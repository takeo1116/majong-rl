# Experiment Report: exp_057

作成日: 2026-03-17  
対象: [experiments/exp_057/runbook.md](/home/takeo1116/Git/majong-rl/experiments/exp_057/runbook.md)  
目的: `imitation=0 + policy_ratio=0.0 + mixed_ppo + gae=0.0 + shanten_delta.scale=0.003` を固定し、`gamma=0.95 / 0.75 / 0.50` を **30 cycles** まで延長したときに、10 cycle では見えにくかった peak 位置と戻りがどう変わるかを確認する

## 3. 10 cycle から 30 cycle で何が見えたか

`exp_056` では 10 cycle 時点で
- `gamma=0.75` と `0.50` はかなり安定
- `best->final` の戻りも小さい
ように見えていた。

30 cycle に延ばした今回の結果は、
- **3 条件とも最終的には戻る**
- ただし `0.75 / 0.50` は `0.95` より明らかに強い
- **`0.50` が最終着地でもっとも良い**
というものだった。

つまり、10 cycle の時点では
- `0.75 / 0.50` は「安定」ではなく
- **まだ peak 近傍を見ていた**
と解釈するのが自然。

## 7. 診断補足

終盤の `turn_diag.late.value_error.mean`（final cycle 平均）:

| 条件 | late.value_error.mean |
|---|---:|
| A `0.95` | `+0.00256` |
| B `0.75` | `+0.00017` |
| C `0.50` | `-0.00123` |

所見:
- `gamma` を下げるほど終盤 value 誤差は小さくなる。
- `0.95` で残っていた終盤誤差が、`0.75 / 0.50` ではかなり圧縮されている。
- したがって今回の改善は、単なる見かけではなく **long-horizon bootstrap 由来の誤差低減** と整合する。

## 8. 解釈

今回かなり強く言えること:

1. `gae=0.0` にしても、`gamma=0.95` はまだ長すぎた。  
2. `gamma=0.75 / 0.50` に下げると、peak が後ろへずれ、final も改善する。  
3. ただし **戻りは完全には消えず**、`0.50` でも長サイクルでは少し崩れる。  
4. つまり `gamma` は plateau / 戻りの主因の一つだったが、**唯一の主因ではない**。  
5. 30 cycle まで見た現時点の有望帯は、`0.75` よりやや `0.50` 寄り。

## 9. 結論

1. `exp_057` により、「10 cycle では安定に見えた条件も、30 cycle では戻る」ことが確認できた。  
2. それでも `gamma=0.50 / 0.75` は `0.95` より明確に良く、`gamma` 改善の方向性自体は正しかった。  
3. 最有力条件は現時点では **`gamma=0.50, shanten_delta.scale=0.003, gae=0.0`**。  
4. 次段は `gamma` の微調整よりも、**この条件を固定して、まだ残る戻りの原因を target / reward 側で見る**方が情報価値が高い。
